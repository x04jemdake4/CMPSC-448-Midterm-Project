# CMPSC-448-Midterm-Project
We built a dataset of (LLM_name, LLM_input, LLM_output) triples from 3 LLM families (GPT, Claude, and Llama). W trained a CNN and an RNN (BiLSTM) to identify which LLM wrote a response. And investigated whether the prompts helps (RQ2) and what distinguishes the LLMS (RQ4), plus extra credit on generalization across tasks (RQ3).

Collaborators: Ryan Broadhurst (team leader) and Michael Finn
